# 风格预设管理 · 界面使用文档

> 页面：`http://localhost:5173/styles`（需登录）· 入口：「我的 → 账号设置 → 风格预设」

## 1. 功能总览

风格预设用于管理 AI 出图的视觉风格。创作页与项目详情页的风格选项**实时读取**此处启用的预设，无需改代码即可增删风格。

| 能力 | 位置 |
|---|---|
| 查看全部 / 含已停用 | 工具栏「显示已停用」开关 |
| 新建风格 | 页头「新建风格」按钮 |
| 编辑风格 | 卡片「编辑」按钮 |
| 启用 / 停用 | 卡片右下开关 |
| 删除风格 | 卡片「删除」按钮（二次确认） |

## 2. 列表页

进入 `/styles` 后自动加载，卡片网格按 1 / 2 / 3 列响应式排布（640px / 1024px 断点），带滚动入场动效。

每张卡片显示：
- **风格名称**（单行省略）
- **状态标签**（启用=绿色 / 停用=灰色）
- **简介**（最多两行）
- **提示词预览**（等宽字体，最多两行）
- 底部操作区：启停开关 + 编辑 + 删除

停用卡片整体降低透明度以便区分。首次进入时若账号无预设，后端会自动写入 6 条默认风格。

**空状态**：显示虚线引导卡与「新建风格」入口。
**加载失败**：显示「重试」按钮，点击重新拉取。

## 3. 新建 / 编辑

点击「新建风格」或卡片「编辑」打开弹窗，字段如下：

| 字段 | 必填 | 规则 |
|---|---|---|
| 风格名称 | 是 | 1-64 字符，自动去除首尾空格，同账号内不可重复 |
| 提示词 | 是 | 最长 2000 字符，带字数统计；建议用英文关键词，如 `cyberpunk, neon lights, futuristic city` |
| 简介 | 否 | 最长 256 字符，展示在风格卡与创作页选项上 |
| 负向提示词 | 否 | 最长 2000 字符，出图时排除的元素 |
| 排序 | 否 | 0-999，数字越小越靠前 |

- 名称重复时后端返回 400，弹窗内名称字段直接标红并提示「风格名称已存在」，修改后错误提示自动清除。
- 保存期间按钮进入 loading 并禁用，避免重复提交。
- 取消按钮关闭弹窗，不保存改动。

**示例**：新增「国潮工笔」
```
名称：国潮工笔
提示词：chinese traditional gongbi painting, fine brushwork, silk texture, elegant
简介：工笔重彩、东方韵味
负向提示词：photo, realistic
排序：5
```
保存后回到创作页，风格网格中即出现「国潮工笔」及其简介。

## 4. 启用 / 停用

点击卡片右下开关即时切换。切换为**乐观更新**（界面立即响应），请求失败会自动回滚状态并提示错误。

停用后的风格**不再出现**在创作页与项目详情编辑弹窗的风格选项中，但已使用该风格的历史项目不受影响。

## 5. 删除

点击「删除」弹出确认框（显示风格名称，提示不可恢复）。确认后删除并即时从列表移除，同时同步刷新创作页的选项数据。

> 建议：若只是想临时隐藏某个风格，用「停用」而非删除。

## 6. 与其他模块的联动

- **创作页**（`/create`）：风格选择区读取启用中的预设，显示名称 + 简介；提交时仍保存风格名称，与后端生成链路兼容。
- **项目详情**（编辑弹窗）：风格下拉同样使用动态预设列表。
- **AI 出图**：生成画面时按项目风格名匹配预设，自动使用其提示词与负向提示词，因此**修改预设提示词会影响后续新生成的画面**，可在不重新部署的情况下调优出图效果。
- 后端未就绪或网络异常时，前端自动回退到内置的 6 个默认风格，保证创作流程不中断。
